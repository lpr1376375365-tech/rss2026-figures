# RSS 2026 图表库（VLA / Agentic Robotics）

这是 RSS 2026 论文的配图合集，用来积累论文配图的审美参考。收录 VLA 和 agentic robotics 方向的 58 篇论文（其中 4 篇是对照组），共 512 张图：主图 58、方法图 88、实验图表 195、实验设置 66、定性结果 93、其他 12，其中 ★ 精选 59 张。

实验图表细分：柱状图 64、折线图 55、组合图 44、散点图 12、热力图 11、箱线/小提琴 4、雷达图 3、饼/环图 2。这批论文里单独的饼图很少，环形图大多和其他图表画在一起，归在“组合图”里。

- 按类别筛选：主图、方法图、实验图表（柱状图、折线图、饼/环图、散点图、热力图、雷达图、箱线/小提琴图、组合图）、实验设置、定性结果
- ★ 精选：版式或配色特别出色的图，每张附一句点评
- 两种浏览方式：“按类别”和“按论文”；还可以按研究方向筛选，或搜索标题、图注、作者
- 点击图片看大图和完整图注，键盘 ← / → 翻页，Esc 关闭；可以直接跳到 PDF 里对应的页

## 怎么打开

https://lpr1376375365-tech.github.io/rss2026-figures/

## 文件

- `index.html`：浏览页面
- `data.js`：论文和图片的元数据（标题、作者、方向、图注、类别、★ 点评）
- `img/`：裁好的图片，命名为 `p<论文编号>_fig<图号>.jpg`。论文编号对应 roboticsproceedings.org/rss22/ 上的编号
